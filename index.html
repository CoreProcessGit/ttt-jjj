Core Features

Everything you need for
test management in Jira

T-CAFE integrates seamlessly with Jira Cloud to provide
a complete test management solution for your team.

Test Case Management

Create and manage test cases with folders, steps, preconditions, and user-defined fields.

  • Single & Factor Combination types
  • Test steps with expected results
  • Import/Export (CSV, JSON, Excel)

Test Plan & Execution

Organize test cases into plans and track execution with real-time progress monitoring.

  • Pass / Fail / Block / Skip tracking
  • Milestone timeline view
  • Comments & Jira issue linking

Reports & Analytics

Generate detailed test reports with execution statistics and exportable data.

  • Execution rate & pass/fail charts
  • Export reports (CSV, Excel)
  • Daily progress tracking

Factor Combination

Generate optimized test combinations to maximize coverage with minimal test cases.

  • Full / Pairwise / Mixed algorithms
  • Constraint rules (If-Then, Mutual Exclusion)
  • Steps matrix with TC mapping

Jira Issue Integration

Create and search Jira issues directly from test execution and link them to test cases.

  • Create issues with auto-filled details
  • Search and link existing issues
  • Retestable tracking on issue completion

Attachment Management

Upload and manage test artifacts with drag-and-drop support and secure storage.

  • Drag & drop file upload
  • Supported formats guide
  • Data encrypted & secured

Configuration

Customize priorities, case types, components, plan statuses, and user-defined fields.

  • Custom priorities & case types
  • User-defined fields (9 types)
  • Plan status & component management

User Permissions

Flexible role-based access control with system roles and custom roles.

  • 4 system roles + custom roles
  • Per-project permission control
  • User activate / deactivate

Multi-Language

Full internationalization support with automatic language detection from Jira settings.

  • English, Korean, Japanese
  • Auto-detect from Jira locale
  • Per-project language setting
