Getting Started & Overview

01Installation & First Steps

Install T-CAFE on Jira Cloud, sign in, and create your first project. Includes Welcome Banner & Sample Data.

02User Roles & Permissions

Admin / Team Admin / Tester / Developer system roles, custom roles across 8 permission areas, and self-demotion guards.

03Overview Dashboard

Welcome Banner, Board, Count cards (Test Cases / Test Plans / Total Users), Test Milestone Gantt, and Status Kanban.

04Board (Announcements)

Embedded project board with rich-text post creation (Admin only), pagination, and view counts.

Test Cases

05Test Case Management

Create, edit, view, clone, move, and delete test cases. Created/Updated columns, filters, and bulk actions.

06Folder Management

Organize test cases into folders with rename, move, copy, and impact-aware delete (TCs deleted with folder).

07Test Steps

Write detailed test steps with Step / Test Data / Expected Result. Embed [ATTACHMENT:…] tags for clickable downloads.

08Factor Combination

Auto-generate test combinations with Pairwise (greedy + random sampling), Full Combination, or Mixed mode. Constraints supported.

09Import / Export

Import CSV / JSON / Excel up to 5,000 cases (auto-merge). Export to CSV / JSON / Excel with full column set.

Test Plans & Reports

10Test Plan Management

Create test plans, add/remove TCs, clone (without TPTCs), folder organization, and status workflow.

11Test Execution

Execute TPTCs (Pass / Fail / Block / Skip), log comments, and create Jira issues from failures.

12Test Reports & Analytics

View execution stats by Folder / Component / Tester. Filter by Status / Owner / Progress. Export to Excel.

Configuration & Resources

13Configuration

Customize Priorities (4 default), Case Types (6 default), Components, Plan Statuses (Draft/Open/Completed), and User-Defined Fields.

14Attachments

Upload, manage, and link files. Project storage cap 200 MB. Use [ATTACHMENT:id:filename] tags inside TCs/TPs for clickable downloads.

15Frequently Asked Questions

Common questions on installation, permissions, test cases, factor combination, attachments, security, billing, and compatibility.
